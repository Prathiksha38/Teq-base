# TeqBase – Student Data Management & Staff Daily Reports

## Project Overview

TeqBase is a full-stack web application designed to manage **student records and staff daily reports**.
The backend is developed using **Django and Django REST Framework**, while the frontend is built using **React**.

The system helps organizations track student information and monitor staff work reports efficiently.

---

## Tech Stack

### Backend

* Python
* Django
* Django REST Framework
* PyMongo (MongoDB connectivity)

### Frontend

* React
* React Router DOM
* Axios
* React Bootstrap
* React Icons

---

## Installed Packages

### Backend (Django)

```bash
pip install django
pip install djangorestframework
pip install pymongo
```

### Frontend (React)

```bash
npm install react-router-dom
npm install react-icons
npm install axios
npm install react-bootstrap
```

## How to Run the Project

### Backend

```bash
python manage.py runserver
```

Backend runs at:

http://127.0.0.1:8000/

---

### Frontend

```bash
npm start
```

Frontend runs at:

http://localhost:3000/
